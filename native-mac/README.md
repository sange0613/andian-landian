# 暗淡蓝点 Mac 原生轻量版

中文界面，作者：戌無营造。macOS 12 及以上，支持 Apple Silicon 和 Intel。

## 安装

推荐双击 `暗淡蓝点-1.2.6-Mac-安装包.pkg`，按提示安装到“应用程序”。
之后在启动台搜索“暗淡蓝点”，点击打开；已运行时再次点击只打开设置。
也可打开 `暗淡蓝点-1.2.6-Mac-通用轻量版.dmg`，把应用拖进 `Applications`。
本地交付目录为 `dist/暗淡蓝点-Mac-轻量版-1.2.6/`。
不要一直从 DMG 或源码 dist 目录运行，否则不是安装到启动台的应用。

应用仅做本地 ad-hoc 签名，PKG 未做开发者签名，两者没有 Apple 公证。
网络下载后首次打开若被系统拦截，可在系统设置的“隐私与安全性”中允许打开。
不要关闭系统安全检查。轻量版与旧版本相互独立，确认可用后再卸载旧版。

## 使用

- 双击蓝点开始、暂停或继续；左键按住拖动。
- 桌面蓝点右键、状态栏左键单击打开菜单，可隐藏蓝点、打开设置或完全退出。
- 隐藏蓝点或关闭设置后，计时继续；状态栏菜单的“显示蓝点”可手动恢复圆点。
- 隐藏后单击、双击状态栏，或再次打开已运行的程序，都不会自动显示圆点。
- 状态栏显示蓝点和剩余分钟，左键单击打开菜单；该菜单不显示“暂停”。
- 左键双击状态栏直接开始、暂停、继续，不弹菜单，也不显示隐藏的桌面蓝点。
- 单击立即完整显示无动画菜单，不等待双击判定；双击关闭菜单并切换计时。
- 紧凑菜单宽 144pt、行高 22pt、边距 6pt。
- 点击菜单外部或按 Esc 关闭；菜单使用系统原生非阻塞弹出层，不在显示途中重建。
- 未开始或暂停时蓝点为 10pt、不透明；计时中保持原来的 8pt，并变为 60% 不透明。
- 图标画布固定为 14pt，不移动相邻图标、不播放常驻动画。
- 设置提供 5、25、45 分钟，支持自定义 1 到 180 的整数分钟。
- 开始计时后蓝点半透明，暂停后恢复不透明。
- 时间到响一声，蓝点最多放大三倍，状态栏闪烁；连续点击桌面蓝点三下取消，
  也可从状态栏菜单选择“取消提醒”。
- 隐藏状态下时间到，仍会自动弹出圆点动画；三击取消或重置后恢复隐藏。
- 记住时长和位置，退出后不会自动恢复未完成的计时。

## 体积

原生通用应用约 **300KiB**，压缩 DMG 约 **111KiB**，PKG 约 **82KiB**。
每次构建的准确大小见 `build-report.json`。
磁盘实际分配空间会因文件系统不同略有差异。

只使用系统 AppKit、Foundation 和 C++ 标准库；没有浏览器、WebView、字体、
第三方依赖或捆绑运行库。共用 Windows 原生版的计时与鼠标逻辑。
常态一秒检查一次计时，只有到点提醒时启用动画。

## 构建与验证

开发环境需要 Xcode Command Line Tools 和 Node.js（仅用于构建产物检查，用户无需安装）。

```bash
bash native-mac/build.sh
bash script/build_and_run.sh --verify
```

构建时运行 C++ 回归测试和真实 AppKit 控件交互测试，生成 arm64/x86_64 通用应用，
检查系统依赖、签名、渲染、自定义输入、拖动和双击、隐藏后状态栏交互，
以及 DMG 和 PKG 与原应用逐文件一致性。安装包固定安装到 `/Applications`，
不搜索并覆盖 dist 中的旧副本，也没有额外安装脚本。
整个应用超过 1MB 或安装包超过 2MB 时构建失败。
报告位于交付目录的 `build-report.json`；截图位于 `dist/mac-native-build/verification-*/`。

已在 Apple Silicon Mac 运行验证；含 Intel 架构，但未在实体 Intel Mac 上测试。
