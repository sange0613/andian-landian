# Win10 关闭到托盘设计

## 目标

在 Windows 10 上通过系统的“关闭窗口”操作关闭桌面蓝点时，不退出程序，而是隐藏到右下角系统托盘并继续计时。

## 交互

- 仅 Windows 主悬浮窗拦截普通关闭事件。
- 关闭时隐藏桌面蓝点，保留托盘图标，渲染进程和倒计时持续运行。
- 蓝点隐藏时，单击托盘图标恢复蓝点；托盘右键菜单中的“显示蓝点”也能恢复。
- 蓝点可见时，Windows 托盘单击仍用于开始或暂停。
- 设置窗口的关闭按钮只关闭设置窗口，不影响主计时器。
- 右键菜单和设置中的 `Quit` 是真正退出，不被关闭拦截。
- 隐藏期间计时结束时保持隐藏，仍播放提示音。

## 实现

主进程记录是否正在真正退出。在 Windows 主窗口的 `close` 事件中，普通关闭会调用 `preventDefault()` 并隐藏窗口；`before-quit` 之后的关闭则允许销毁窗口和退出进程。Mac 关闭行为不变。

## 测试与交付

- 测试 Windows 普通关闭返回隐藏动作。
- 测试真正退出和非 Windows 平台允许关闭。
- 测试托盘在蓝点隐藏时返回恢复动作。
- 版本升级为 `1.0.15`，运行完整测试并构建 Win10 x64 安装包。
